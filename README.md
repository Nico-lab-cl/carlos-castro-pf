## 🎨 Identidad Visual y Paleta de Colores

Basada estrictamente en el logotipo oficial con estética de guerrero/samurái y pesas olímpicas:

## 🌐 Cómo Publicar el Sitio Web (100% Gratis en 2 Minutos)

### Opción A: Vercel o Netlify (Recomendado)
1. Ve a [vercel.com](https://vercel.com) o [netlify.com](https://netlify.com).
2. Arrastra la carpeta completa `pf-carlos-castro-bio` en la sección "Deploy".
3. En 10 segundos tendrás una URL lista (ej: `pfcarloscastro.vercel.app`) para poner en la bio de Instagram.

### Opción B: GitHub Pages
1. Sube los archivos a un repositorio en GitHub.
2. Ve a **Settings** > **Pages** > Selecciona rama `main` y guarda.
3. Tu Link in Bio estará activo gratuitamente.
